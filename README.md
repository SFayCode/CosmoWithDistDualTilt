# CosmoWithDistDualTilt
Codes for fitting dark energy (LCDM and w0waCDM) with a distance duality tilt and DESI BAO, cosmic chronometers and four sets of supernoave.

The data directory contains the CC and SN data (the BAO data are in the Mathematica files).
The chain directory contains the chains.

The Mathematica files allow to parametrise epsilon=0 or not and the SN data source. To use a chain, copy it in the same repertory as the Mathematica file.
